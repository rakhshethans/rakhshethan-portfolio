Computer vision · Desktop app

Real-Time Audio Narration

Turns webcam scenes into spoken descriptions.

Python · PySide6 · PyTorch · Qwen3-VL · Kokoro

GitHub

Accessibility prototype.

Inside the build
  • A vision-language model interprets frames; speech synthesis reads its output unchanged. Both run on-device.
  • Camera capture and speech run separately, so sentences finish without interruption.

Speech begins 6.61 seconds into this demo, excluding model loading. Recognition can invent details: a separate book-photo test produced an unsupported pen reference. Narration is not professional film quality.

Finance · Hackathon project

Opportunity Cost Engine

Compares a retail purchase with projected returns from investing the same amount in the retailer’s stock. Three forecasting models generate projections, with headline sentiment providing a small, capped adjustment.

Python · Flask · JavaScript · TextBlob · Chart.js

GitHub
Inside the build

My contribution

  • Built the browser flow for company selection, forecasting models, time horizons and API submission.
  • Integrated Flask endpoints with the JavaScript interface, presenting purchase values, investment projections and uncertainty bands through interactive Chart.js visualisations.
  • Implemented the headline sentiment-analysis pipeline using yfinance and TextBlob.

Built in two days by a four-person team at the Warwick Finance Societies Hackathon, with Amogh Naik Gaunekar, Alan Siby and Shane Sebastian.

How it works

Flask returns model projections for the JavaScript interface to visualise in Chart.js. Recent company headlines are scored with TextBlob, providing a small, capped adjustment to stock-growth projections.

Limitations

Projections are illustrative, not guaranteed outcomes. Headline sentiment is an experimental heuristic rather than a validated predictor of future returns.
